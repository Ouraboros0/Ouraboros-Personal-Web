Genesis

I'm Gen — a software engineer who thinks in systems and feels in cycles. I write code the way one writes a journal: honestly, iteratively, and always with the awareness that what's built today will be torn down and rebuilt into something truer tomorrow.

The name Ouraboros is intentional. Not the ancient serpent — something personal. A reminder that growth isn't linear. Every project, every problem, every version of me feeds the next.

I work across the full stack, drawn particularly to the places where logic meets feeling — interfaces that think, systems that breathe, code that carries intention.
